# DESCRIPTION
Developed as part of my Python Programming internship at CODTECH IT SOLUTIONS, this application performs real-time weather data analysis. It integrates with the OpenWeatherMap API to retrieve current weather conditions for various cities. The data is processed using Pandas and visualized through interactive dashboards with Matplotlib and Seaborn, highlighting temperature and humidity comparisons. This project demonstrates proficiency in API integration, data processing, and visualization.
